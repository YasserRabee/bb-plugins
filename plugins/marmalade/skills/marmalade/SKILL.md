# Marmalade theme

Select **Marmalade** in Settings → Appearance (or `bb theme set plugin:marmalade:marmalade`).
All values are hard-coded in `themes/marmalade.css`; edit it, then `bb plugin build` and `bb plugin reload marmalade`.
JetBrains Mono is not bundled; it must be installed on the machine.
